# PyQQ Bot

基于 NapCat (Docker) + OneBot v11 WebSocket 的 QQ 群管理机器人。

## 功能

**自动功能:**
- 违禁词检测 → 自动撤回消息 → 累计 3 次违规 → 自动禁言 1 天
- 新人入群自动欢迎

**中文命令 (无需前缀):**

| 命令 | 说明 | 权限 |
|------|------|------|
| `签到` | 每日签到，随机获得积分 | 所有人 |
| `排行` | 查看签到排行榜 | 所有人 |
| `积分` | 查看我的积分 | 所有人 |
| `帮助` | 显示帮助菜单 | 所有人 |
| `群信息` | 查看群信息 | 管理员 |
| `查违规 @用户` | 查看用户违规记录 | 管理员 |

## 违禁词配置

编辑 `config.py` 中的 `BANNED_WORDS` 列表添加/删除违禁词:

```python
BANNED_WORDS = [
    "广告", "加群", "兼职", "刷单", "代理",
    "赌博", "彩票", "色情", "黄片", "约炮",
    "贷款", "信用卡", "套现", "办证", "刻章",
]
```

违规阈值 `VIOLATION_MUTE_THRESHOLD = 3` 表示累计 3 次后禁言 1 天。

## 快速开始

```bash
pip install -r requirements.txt
python main.py
```

## 项目结构

```
pyqq-bot/
├── main.py              # 主入口，WebSocket 连接
├── bot.py               # 核心逻辑，命令路由 + 违禁词检测
├── config.py            # 配置文件 (违禁词/阈值/连接地址)
├── plugins/
│   ├── group_manage.py  # 群管理 API (撤回/禁言/发消息)
│   ├── sign_in.py       # 签到系统
│   └── violation.py     # 违禁词检测 + 违规追踪
└── data/                # 数据存储 (自动创建)
```

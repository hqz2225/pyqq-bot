# PyQQ Bot

基于 NapCat (Docker) + OneBot v11 WebSocket 的 QQ 群管理机器人。

## 功能

**自动功能:**
- 违禁词检测（含脏话）→ 自动撤回 → 累计 3 次违规 → 禁言 1 天
- 新人入群自动欢迎（支持自定义）

**中文命令 (无需前缀):**

| 命令 | 说明 | 权限 |
|------|------|------|
| `签到` | 每日签到 | 所有人 |
| `排行` | 签到排行榜 | 所有人 |
| `积分` | 查看我的积分 | 所有人 |
| `兑换` | 查看兑换列表 | 所有人 |
| `兑换 编号` | 兑换指定物品 | 所有人 |
| `帮助` | 显示帮助 | 所有人 |
| `群信息` | 查看群信息 | 管理员 |
| `查违规 @用户` | 违规记录 | 管理员 |
| `设置欢迎 xxx` | 改入群欢迎 | 管理员 |
| `查看欢迎` | 当前欢迎消息 | 管理员 |
| `添加兑换 名称 积分` | 添加兑换物 | 管理员 |
| `删除兑换 编号` | 删除兑换物 | 管理员 |
| `加积分 @用户 数量` | 加积分 | 管理员 |
| `扣积分 @用户 数量` | 扣积分 | 管理员 |
| `更新` | 拉代码重启 | 管理员 |

## 快速开始

```bash
pip install -r requirements.txt
python main.py
# 或保持运行:
bash start.sh
```

## 配置

编辑 `config.py`:
- `WS_URL` - WebSocket 地址
- `BANNED_WORDS` - 违禁词列表
- `VIOLATION_MUTE_THRESHOLD` - 违规禁言阈值
